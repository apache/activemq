Apache ActiveMQ 5.18.0 was released on Mar 24th, 2023. It's a major milestone for the ActiveMQ.
ActiveMQ 5.18.x brings:
* It brings initial JMS 2.0 (javax.jms API namespace) and Jakarta Messaging 3.1 (jakarta.jms API namespace) client support. See the [JMS 2.0 page](/components/classic/documentation/jms2) for more details on the available functionality and how to use the Jakarta Messaging support.
* Spring 5.3.x
* optimized LDAP use in LDAP JAAS login module
* improved REST API
* improved redelivery policy
* a lot of dependency updates
* and much more!

You can find details on the [release notes](https://issues.apache.org/jira/secure/ReleaseNote.jspa?projectId=12311210&version=12351380).
