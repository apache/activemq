# Apache ActiveMQ Website

This is the source code for the [ActiveMQ website](https://activemq.apache.org/). It is a static website built with [Docusaurus](https://docusaurus.io/), client-side search is provided by [PageFind](https://github.com/toasty-kj/docusaurus-plugin-pagefind) and Maven integration is done via [frontend-maven-plugin](https://github.com/eirslett/frontend-maven-plugin). The project is based on [activemq-website](https://github.com/apache/activemq-website) for content and layout, it was also built on top of [apache-website-template](https://github.com/apache/apache-website-template/tree/docusaurus).   

## Prerequisites

- Java 11+ and Maven 3.6+

## Usage

### Start Development Server

```bash
mvn frontend:pnpm@start
```

Launches the Docusaurus dev server with hot-reload at `http://localhost:3000`.

Documentation search uses a [Pagefind](https://pagefind.app/) index that is only generated by a production build. To use search with the dev server, run:

```bash
mvn frontend:pnpm@start-search
```

This does a full build, copies the index to `website/.pagefind`, then starts the dev server. Later runs of `mvn frontend:pnpm@start` reuse that index until `mvn clean`. The index doesn't update as you edit pages.

### Full Build

```bash
mvn package
```

This will:
1. Install Node.js v22.16.0 and pnpm 11.9.0 (if not already cached)
2. Run `pnpm install` to fetch dependencies
3. Run `pnpm run build` to produce the static site
4. Copy the build output to `target/website/`

### Clean

```bash
mvn clean
```

Runs `pnpm run clear` to remove the Docusaurus generated files and then the standard Maven `target/` cleanup.

## Adding new ActiveMQ releases

Each new ActiveMQ release is documented in `src/data/releases/classic/*.mdx`. The information about new releases is included in
different places: the card in the main page, downloads, news, in the RSS feed, etc... . To make it more convenient, the
`genererate-release-news.ts` script automatically generates all the necessary changes. The script runs as part of the build. 

To include a new release you just need to add a new `.mdx` file under `src/data/releases/classic/`.

## Updating documentation

All documentation lives under `/docs`. Just update the `.md` files. The documentation is based on [Docusaurus's Docs plugin](https://docusaurus.io/docs/docs-introduction). For details on how the documentation page sidebar is configured, refer to https://docusaurus.io/docs/sidebar.
